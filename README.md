# Pencil Case

A minimal hard-shell pencil case. Personal industrial design project — from concept and CAD to photorealistic visualization, prepared for small-batch production.

![Pencil case on a desk](images/01-desk.jpg)

## Design

A rounded rectangular shell with a soft-touch matte finish, a contrasting cobalt-blue latch as the single color accent, and a dark elastomer base. The hinged lid carries an integrated metal ruler; the tray is compartmentalized for pens, pencils, an eraser and a sharpener.

- One-hand opening: center latch, stiff hinge holds the lid at working angle
- Lid doubles as a tool panel — removable ruler on retention clips
- Molded tray keeps instruments in place when carried vertically
- Non-slip elastomer base
